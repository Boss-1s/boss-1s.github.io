    Coding/Development

    I use GitHub (obviously) and Turbowarp. I also scarcely use Code.org for testing in a sandboxed environment. I used to use Scratch, but sadly got banned because I overused scratchattach. Honestly, I don’t care about Scratch as much as I used to; it’s been crumbling on itself for a long time…

    Anyways, as for devices, I use a Lenovo Chrome 500e (before that, I used a Chromebook Acer Spin 514), which is the device i use for everything (literally), a 3DS, a Raspberry Pi Pico 2W and a Raspberry Pi 3B. Using a Chromebook for development is definitely hard, but i’ve managed it for a while, and it should be fine.

    Currently working on kms and helping out on scratchattach. I’m also working on a TurboWarp port of Geometry Dash, titled (aptly) Geometry Dash: TurboWarp Editon or GDTW.
