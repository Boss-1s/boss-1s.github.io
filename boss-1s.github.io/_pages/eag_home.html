Eaglercraft - What You Need to Know


Click here to skip to actual playing.

  • What is EaglerCraft?

    • EaglerCraft is a Minecraft clone that runs in your browser.
    • It is a fork of the original Minecraft game, and it is not affiliated with Mojang or Microsoft.

  • What are the different types of EaglerCraft?

    • EaglerCraft is the original version of EaglerCraft, based on a version of Minecraft 1.5.2.
    • EaglerCraftX is a fork of EaglerCraft based on Minecraft 1.8.8, and is the most popular type of EaglerCraft.
    • EaglerCraftZ is a fork of EaglerCraft based on Minecraft 1.20, and is the most recent type of EaglerCraft.
    • EaglerLite is NOT a type of EaglerCraft - rather, it is a launcher that allows you to load EaglerCraft more stably on low-end devices like Chromebooks.
    • EaglyMC is a fork of EaglerCraftX that takes blocks and entites up to Minecraft 1.20 and backports them to Minecraft 1.8.8. However, EaglyMC is still run on Minecraft 1.8.8, meaning certain biomes, structures, and features are limited and/or not added.

  • What are the different versions of EaglerCraft?

    • Each version of EaglerCraft listed below matches the Minecraft version it is based on and attempting to recreate.
    • For example, EaglerCraft 1.12.2 is based on Minecraft 1.12's "the World of Color Update", and EaglerCraftX 1.20.6 is based on Minecraft 1.20's "Trails and Tales" update.

  • WebAssembly (WASM) vs. JavaScript (JS)

    • WASM is a newer technology that allows for faster and more efficient execution of code in the browser. It is generally recommended to use WASM versions of EaglerCraft if your device supports it.
    • Basically, EaglerCraft in WASM takes the original Minecraft code and compiles it to WebAssembly, which is a more efficient way to run the code in the browser.
    • JS is an older technology that is slower and less efficient than WASM, but it is more widely supported by older devices and browsers.
    • Using JavaScript allows for more compatibility with older devices and browsers, but at the cost of performance. It is recommended to use WASM versions when possible, and only fallback to JS if necessary.
